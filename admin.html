上游协议设计与特性局限性说明 由于 Command Code 官方 $1 Go 套餐仅开放私有 CLI 端点 (/alpha/generate)，反代协议与标准开放 API 存在以下设计局限性：
技术特性透视
模型权限门槛 (Plan Gating) 403 Blocked
Go 套餐仅支持指定模型（如 Qwen、DeepSeek 系列、MiniMax、GLM 等）。若请求 Claude 3.7 Sonnet 或 GPT-5.4 等顶级模型，上游服务端会直接返回 403 权限拒绝（需要官方 Pro 或更高级套餐）。
缓冲式流式传输 (Buffered Stream) SSE Batch
上游接口包含内部 Agentic 思考排队机制，且 CPA 动态库执行器基于整块内存转发。首字延迟 (TTFB) 约等于整段生成耗时 (~3-5s)，生成完成后一次性快速推流，暂非打字机逐字延迟。
缓存不可控与统计缺失 (Prompt Caching) Opaque Cache
上游未暴露 Anthropic 显式缓存标点 (Cache Control) 或 OpenAI 缓存参数。返回的 Usage 仅提供输入与输出 Token 总数，无法向客户端透传 cached_tokens 精准节省统计。
高级生成参数过滤 (Schema Constraints) Sanitized
上游 /alpha/generate 严格校验入参 Schema，仅支持 temperature、max_tokens 与 reasoning_effort。为避免上游报 400 Bad Request，插件主动清洗了 top_p、presence_penalty、stop、seed 等参数。
结构化输出与分词限制 (JSON & Tokenizer) Prompt Guided
上游缺乏底层的 Grammar/BNF 语法树强制约束引擎，无法保证原生强制 JSON 格式化输出（需依靠 Prompt 引导）；插件本地 Token 计数采用字符启发式预估。
